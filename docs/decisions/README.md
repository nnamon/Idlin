# Decision records

Create one short Markdown file for each consequential, difficult-to-reverse choice.
Use the next sequence number and a descriptive name, such as
`0001-example-decision.md`.

## Template

```markdown
# Decision title

Status: proposed | accepted | superseded
Date: YYYY-MM-DD

## Context

What forces and constraints make a decision necessary?

## Options considered

What realistic alternatives were considered?

## Decision

What was chosen and why?

## Consequences

What becomes easier, harder, or impossible?
```
