# 0014: Skills, the bag and the bank

Date: 2026-11-27. Made in #235, skills part 1.

| Decision                                                                                                                                                      | Rejected alternative                                  | Why                                                                                                                                                                                                 |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Experience is stored per skill; the level is worked out from it with a fixed table (level 2 at 83, level 99 at 13,034,431), built with whole numbers only.    | Store levels, or build the table with `Math.pow`.     | Experience is what grows; a level is a view of it. Integer arithmetic keeps the table the same on every machine, which the determinism rule asks for.                                               |
| Melee and Hitpoints give 4 experience per hitpoint a blow actually took, so overkill counts for nothing.                                                      | A flat amount per blow landed or taken.               | Per hitpoint scales with stronger blows and stronger monsters without new numbers, and a finishing blow on a nearly dead monster cannot be farmed.                                                  |
| Levels change nothing yet: an adventurer has 20 hitpoints at any Hitpoints level.                                                                             | Raise maximum hitpoints with the Hitpoints level now. | That changes every fight's balance and is better done with gear and food in the later skills issues, where it can be tuned together.                                                                |
| Goods (`logs`, `raw_fish`, `cooked_fish`) are a fixed list in the simulation with permanent ids, and their names are known to every program like place names. | Goods as content files.                               | Programs name goods by number and the bank is a count per good, so ids must never move, like system call numbers. Gathering and cooking (part 2) add to the end of the list.                        |
| The bag has 12 slots, one good each, no stacking. The bank is a count per good, one bank per adventurer.                                                      | Stacking in the bag; one shared camp store.           | A bag that fills is what sends a resident home, which is the trip the design asks for. Owning the bank keeps what a program earned its own, and death drops (part 3) only take what was not banked. |
| Banking works standing next to any `bank` tile (the chest), not on the `bank` place itself.                                                                   | Banking only on the `bank` place.                     | Several residents can bank at once from the chest's four sides, and a map with more regions can have a chest in each without a new place name.                                                      |

Version 5 snapshots are still read: everyone starts with no experience and an
empty bag and bank. Version 4 is read through the same step.
