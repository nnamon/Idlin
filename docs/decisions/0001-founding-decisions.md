# 0001: Founding decisions

Date: 2026-11-26. Decided by the conductor under the operator's brief. Each can
be vetoed; see section 8 of [AGENTS.md](../../AGENTS.md).

Rows 8 and 9 (the Kenney art packs and PixiJS) were replaced by
[0004](0004-ink-map-art.md). The three-hour cadence in row 13 was replaced by
[0005](0005-one-long-session.md); one issue per cycle still stands. Which
models review, in row 11, is now set by [0006](0006-models-after-the-switch.md).

| #   | Decision                                                                                                                                    | Rejected alternative                                             | Why                                                                                                                |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| 1   | Start `main` over with a commit that deletes the 1.0 tree.                                                                                  | An orphan branch and a force push.                               | Same result, no history rewrite on a public repo, trivially undone.                                                |
| 2   | TypeScript for simulation, server and viewer.                                                                                               | Rust core with a web viewer (as in 1.0).                         | One toolchain; the same sim runs in server, browser and tests, which makes captures and replays cheap.             |
| 3   | Keep determinism, as a tool.                                                                                                                | A live world with no replay.                                     | Replays make "did this change make it better to watch" a fair before/after comparison, and make bugs reproducible. |
| 4   | Programs are ordered rule lists (Tactics) compiled to bytecode.                                                                             | A general scripting language.                                    | A rule list reads at a glance on a stream and the firing rule can be shown; it is easy to start and still deep.    |
| 5   | Play is made of trips with stakes: unbanked haul drops on death.                                                                            | Stationary grinding; or permadeath.                              | Trips give each stretch of play a beginning, a risk and an outcome to show.                                        |
| 6   | A 24-minute day with night danger.                                                                                                          | A world with no clock.                                           | Rhythm for a 24/7 stream, a picture that changes without cuts, and a real decision for every program.              |
| 7   | The whole world in one fixed frame; a slow spotlight panel; no camera cuts.                                                                 | A camera that follows or cuts between characters.                | Cuts and fast changes were disliked before, and a fixed frame is restful on a second screen.                       |
| 8   | Art from packs that may be redistributed (starting with Kenney's CC0 Tiny Town and Tiny Dungeon), animated in code, under a lighting layer. | The Cute Fantasy pack used in 2.0; generated placeholder shapes. | The repo is public and that pack forbids redistribution; placeholder shapes read as soulless.                      |
| 9   | PixiJS 8 for rendering.                                                                                                                     | Phaser; plain Canvas 2D.                                         | A renderer without a framework's opinions; WebGL for lighting and particles.                                       |
| 10  | Everything runs through Docker Compose.                                                                                                     | Running on the host.                                             | The rule protects the operator's machine, so it was kept although older decisions were released.                   |
| 11  | Merges need green CI, a review by a different model family, and for visible changes a watch judge. No human approval.                       | Human review of each pull request.                               | The operator asked not to be an approval gate.                                                                     |
| 12  | Branch protection on `main` requires the `gate` check, including for admins.                                                                | Trusting each agent to check.                                    | A mechanical stop is cheaper than a rule that can be forgotten.                                                    |
| 13  | A work cycle every 3 hours, one issue per cycle, and one daily digest.                                                                      | Continuous running; several builders in parallel.                | The brief asks for minimal resource use; serial work also avoids merge conflicts.                                  |
| 14  | No licence file yet.                                                                                                                        | Choosing an open-source licence now.                             | Licensing the code is the operator's call.                                                                         |
